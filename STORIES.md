# User Stories

## Katalog
Som en användare vill jag kunna öppna katalogen och se alla böcker som finns i listan, så att jag kan välja vilka böcker jag vill läsa.

## Lägg till bok
Som en användare vill jag kunna lägga till nya böcker med titel och författare, så att de visas i katalogen.

## Mina böcker och favoriter
Som en användare vill jag kunna markera böcker som favoriter i katalogen och se dem på en separat sida under "Mina böcker", så att jag enkelt kan hitta mina favoritböcker.

## Statistik 
Som en användare vill jag kunna se statistik över alla sparade böcker för att se hur många böcker det finns i hela listan och hur många av dem som är mina favoriter.
